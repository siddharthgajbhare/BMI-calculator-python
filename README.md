
# 🧮 BMI Calculator

A simple and interactive **BMI (Body Mass Index) Calculator** built using Python and Tkinter. The application allows users to enter their height and weight using sliders and calculates their BMI along with the corresponding health category.

## 📸 Features

* 📏 Calculate BMI using Height and Weight
* 🎚️ Interactive sliders for height and weight selection
* 🧍 Dynamic human image resizing based on height
* 📊 Displays BMI value instantly
* ❤️ Shows health category based on BMI
* 🖥️ Simple and attractive GUI
* ⚠️ Input validation for invalid values

## 🛠️ Technologies Used

* Python
* Tkinter
* Pillow (PIL)

## 🧮 BMI Formula

BMI is calculated using the following formula:

```text
BMI = Weight (kg) / Height² (m²)
```

## 📊 BMI Categories

| BMI Range    | Category    |
| ------------ | ----------- |
| Below 18.5   | Underweight |
| 18.5 - 24.9  | Normal      |
| 25 - 29.9    | Overweight  |
| 30 and above | Health Risk |
